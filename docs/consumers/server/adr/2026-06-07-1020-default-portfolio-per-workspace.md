# Default Portfolio per Workspace

Gorchestra v1 creates a Default Portfolio for each Workspace while still treating Portfolio selection as a visible Server Consumer concept. The v1 registry and selector can represent multiple Portfolios, and the oldest Portfolio registered for a Workspace is its Default Portfolio. The only v1 creation path provisions a Workspace's first Portfolio during Workspace Provisioning rather than during sign-in. The Workspace Owner is also the Portfolio Owner for this Default Portfolio in v1. We chose this to keep onboarding and authorization simple while preserving the Portfolio boundary for shared Memory, Secrets, Projects, and Portfolio Snapshots.
