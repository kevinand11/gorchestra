# App-owned tenancy, Portfolio-level core

Gorchestra's reusable orchestration core starts at the Portfolio level. The Portfolio owns the graph whose nodes are Goals, Plans, Projects, Deliveries, Slices, and Memories; Links express relevance, provenance, and execution dependencies among those nodes. The core also owns Portfolio-owned Secrets, Executions, Actions, Missions, Decisions, Portfolio Snapshots, and the per-Portfolio storage boundary. Deployed-instance concerns such as Workspaces, Workspace Members, membership history, roles, ownership invariants, authentication, sessions, multi-user management, and the global registry of Portfolios belong to the app layer; future consumers may consume the same core while inferring local authority and exposing no Workspace concept.
