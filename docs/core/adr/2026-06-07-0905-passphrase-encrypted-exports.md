# Passphrase-encrypted Portfolio Snapshots

Exporting a Portfolio creates a passphrase-encrypted Portfolio Snapshot containing the Portfolio storage contents. Core owns the Snapshot format and passphrase encryption/decryption behavior so any Gorchestra consumer can import a Snapshot with its passphrase. A Snapshot always includes Secrets and execution history; it excludes Workspace tenancy/auth/member data. Secret-at-rest encryption before export is consumer-specific: a server app may store encrypted Secret values and decrypt them while creating the Snapshot, while another consumer may use a different protection mechanism.
