# GitHub-only Source Control Projects in v1

Gorchestra v1 Source Control Projects support public GitHub repositories only, using GitHub PATs and pull-request Review Surfaces. The `github` provider means public GitHub.com; GitHub Enterprise Server would be a separate future Source Control Provider if needed. GitHub Repository config includes the required Secret reference Core uses for provider access. Repository config writes validate Portfolio consistency by ensuring the referenced Secret exists, but they do not call GitHub; external GitHub access validation happens during preflight or provider operations. We still use provider-neutral domain language such as Repository and Review Surface because the product model should not be permanently tied to GitHub, while avoiding the complexity of implementing multiple source control providers in v1.
