# Artifact-level revision work

Revision work is modeled as Actions and Agent Runs against the relevant artifact, not as new or reopened Slices. Feedback from a Slice review may produce a Revision Output for work against the Slice Artifact before it is promoted into the Delivery Artifact. Feedback from a Delivery review may produce a Revision Output for work against the Delivery Artifact before Ship. Slices remain the accepted planned work structure; revision work adjusts Slice or Delivery artifacts after human-reviewed feedback planning without changing accepted Slice scope.
