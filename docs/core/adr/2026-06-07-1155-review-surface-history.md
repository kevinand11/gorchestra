# Review Surface history

Review Surfaces may be replaced when the current external review object becomes unusable or provider behavior requires creating a new one. Gorchestra preserves Review Surface history, including external identity facts such as provider IDs or URLs and source/target branch facts for Source Control Review Surfaces, and derives the current Review Surface for ongoing review of a Slice Artifact or Delivery Artifact from that history rather than overwriting the previous Review Surface. The current Review Surface is the latest active Review Surface for the artifact; active means not merged and not closed without merge. For Source Control Projects, a merge observed on any historical Review Surface for a Slice Artifact satisfies Slice promotion when it merges the Slice Branch into the Delivery Branch; this handles replaced pull requests that share the same branch. Delivery Ship likewise depends on observing any Delivery Review Surface merge the Delivery Branch into the Target Branch. This preserves auditability while allowing Source Control Projects to reopen or replace pull requests according to provider capability.
