# Source Control Review Surfaces

Source Control Projects use pull requests as Review Surfaces at both Slice and Delivery levels. A Slice Review Surface is created lazily when accepted Agent Run work has been promoted into the Slice Branch and Slice Branch validation passes, then presents that Slice Branch for review and merge into the Delivery Branch. A Delivery Review Surface is created lazily when all Slices are complete and the Delivery Artifact passes required validation, then presents the Delivery Branch for review and merge into the Target Branch. In v1, Gorchestra creates the initial Review Surface with only required metadata: source branch, target branch, title, and body derived from the accepted Slice or Delivery content. It does not set labels, assignees, reviewers, or comments, and does not update Review Surface metadata or post comments after creation unless a concrete need arises; it updates branches, performs or observes merges where authorized, fetches Feedback, and observes Review Surface state. This review layer is required because merge conflicts or review feedback can arise before Slice work composes into the Delivery Artifact and again before the Delivery ships.
