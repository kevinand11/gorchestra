# Core-owned provider behavior and consumer-provided deployment services

Core owns reusable Portfolio orchestration behavior, including Source Control Provider implementations, Model Provider Protocol implementations, Model Agent runtime orchestration, and portable Snapshot encryption. Core provider implementations use official provider SDKs or stable provider abstraction SDKs by default when available, such as Octokit for GitHub and Vercel AI SDK provider packages for supported Model Provider Protocols, while still validating provider responses before use. Consumers provide deployment services such as Portfolio storage, Secret-at-rest protection and plaintext resolution, sandbox allocation and isolation primitives, Clock and ID generation, logging, event publishing, authentication, authorization, and tenancy. Logging and event publishing are best-effort observational services; storage remains authoritative and logger/event failures do not fail Core operations. We chose this boundary so Server and future CLI consumers get consistent source-control, model-agent, and Snapshot behavior while still allowing each consumer to supply deployment-specific mechanics and security controls.
