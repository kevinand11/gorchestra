# Slice Artifact promotion completion

For Project Source Types with Slice Artifacts, a Slice is complete only after its Slice Artifact is promoted into the Delivery Artifact and the resulting Delivery Artifact passes Slice Delivery Artifact validation. Delivery-level artifact validation remains a separate Action after all Slices are complete, so Slice completion validation and Delivery review readiness are distinct facts. Source Control Project implements promotion when any Review Surface for the Slice Artifact is merged from the Slice Branch into the Delivery Branch, whether Gorchestra performs or observes the merge, then validates the resulting Delivery Branch for that Slice. This keeps Slice completion tied to the authoritative Delivery Artifact rather than to isolated Agent Run or Slice work that may not compose cleanly with the rest of the Delivery.
