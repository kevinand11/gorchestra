# Slice Artifact promotion completion

For Project Types with Slice Artifacts, a Slice is complete only after its Slice Artifact is promoted into the Delivery Artifact and the resulting Delivery Artifact passes required validation. Source Control Project implements promotion when any Review Surface for the Slice Artifact is merged from the Slice Branch into the Delivery Branch, whether Gorchestra performs or observes the merge, then validates the resulting Delivery Branch. This keeps Slice completion tied to the authoritative Delivery Artifact rather than to isolated Mission or Slice work that may not compose cleanly with the rest of the Delivery.
