# Review Surface-sourced Feedback

Gorchestra does not store Review Surface Feedback as authoritative Portfolio data in v1. Each Project Source Type's Review Surface defines how Feedback is fetched when Gorchestra needs to evaluate or display review input for Slice or Delivery work. In v1, Feedback is fetched from the current Review Surface for ongoing review, not from all historical Review Surfaces for the artifact. The Revision Gate is artifact-scoped in v1 rather than tied to individual Feedback items. This keeps the Review Surface as the source of truth for comments and reviews while preserving Gorchestra's rule that Feedback alone does not authorize revision work unless the Revision Gate is open.
