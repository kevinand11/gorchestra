# Review Surface-sourced Feedback

Gorchestra does not store Review Surface Feedback as authoritative Portfolio data in v1. Each Project Type's Review Surface defines how Feedback is fetched when Gorchestra needs to evaluate or display review input for Slice or Delivery work. The Revision Gate is artifact-scoped in v1 rather than tied to individual Feedback items. This keeps the Review Surface as the source of truth for comments and reviews while preserving Gorchestra's rule that Feedback alone does not authorize revision work unless the Revision Gate is open.
