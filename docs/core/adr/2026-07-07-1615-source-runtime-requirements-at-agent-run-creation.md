# Source runtime requirements resolve during Agent Run creation

Model Agent Run creation resolves Project Source Type and Agent Run Purpose source runtime requirements before storing the Agent Run. Source resolution is storage-only, loads trusted Core-owned source context records needed by the Project Source Type × Agent Run Purpose branch without auditing broader relationship consistency, and fails the parent creation operation without storing partial Agent Run state when requirements cannot be resolved; Agent Run Preparation remains responsible for preparing the concrete sandbox and applying the already-materialized desired runtime requirements. This keeps creators immediately aware of source requirement materialization failures and avoids persisted unresolved Agent Runs, while preserving Agent Run Preparation for retryable sandbox/provider and runtime requirement application work.
