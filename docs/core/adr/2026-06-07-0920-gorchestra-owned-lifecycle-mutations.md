# Gorchestra-owned lifecycle mutations

Agent Runs perform goal-directed work and may mutate sandbox artifacts inside a Agent Run Sandbox, such as editing files in a worktree. Gorchestra owns authoritative lifecycle and Project Source Type-specific external mutations such as validating outputs, promoting Slice Artifacts and Delivery Artifacts, merging Slice Branches into Delivery Branches for Source Control Projects, updating Delivery lifecycle fields, pushing branches, creating initial Review Surfaces, and shipping. Delivery queueing and closure are authoritative Delivery lifecycle fields; Actions record execution facts rather than those lifecycle gates. We chose this boundary so intelligence can perform work without directly controlling the workflow engine or Project Source Type integration lifecycle.
