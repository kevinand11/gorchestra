# Stream-friendly Agent Run transcript

Superseded in part by [AI SDK-compatible Agent Run transcript parts](./2026-07-06-0114-ai-sdk-compatible-agent-run-transcript-parts.md), which replaces durable model-message and tool-call start/end choreography with AI SDK-compatible `input-message`, `assistant-message`, and `tool-message` transcript parts while preserving Core turn boundaries and live deltas.

Core stores Agent Run transcripts as ordered Agent Run Events with durable start/end/boundary facts, model/tool outcomes, proposal review facts, interrupt requests, and compaction summaries, while live model/tool update deltas stream to subscribers without becoming durable events. Agent Run is the session root; v1 does not add a separate Session or Checkpoint model. This ADR's original separate cursor model is superseded by [Paginated query envelopes and sortable Core ids](./2026-07-06-1040-paginated-query-envelopes-and-sortable-core-ids.md): Agent Run Event ids now provide transcript ordering, pagination, and intra-transcript references. One Core turn is one AI SDK `streamText` multi-step operation, and each AI SDK language-model call within that turn records its own model-message start/end pair. We chose this shape over storing only final Pi-style session messages, persisting raw AI SDK stream objects, or persisting every streaming delta because Gorchestra needs deterministic replay, steering boundaries, proposal acceptance history, and stream-friendly UI behavior without turning Portfolio storage into a raw telemetry sink. See `2026-07-03-2207-ai-sdk-model-provider-and-agent-run-transcript.md` for the AI SDK-backed transcript refinement.
