# Validation feedback loop

When validation or external operation fails during execution, Gorchestra records the failure evidence and may provide that evidence as input to a later Agent Run. For Source Control Projects, merge conflicts are external operation failures, not Feedback, because they do not come from Review Surface reviewers. The later Agent Run works in its own isolated Agent Run Sandbox and attempts to address the failures; Actions then evaluate the new output and rerun validation. If correction retries are exhausted, execution pauses and Gorchestra raises a Decision rather than automatically abandoning the Delivery. This makes validation and operation failures part of the execution feedback loop without giving Agent Runs authoritative state or allowing unvalidated sandbox changes to leak across Agent Runs.
